# Tray Quick Actions

Use these as pinned notes/commands for quick capture from the system tray.

## Capture task
- Create note from `Templates/Tasks/TaskNote.md`
- Store in `Tasks/` folder

## Capture meeting
- Create note from `Templates/Meetings/Meeting Note.md`
- Store in `Meetings/` folder

## Open dashboard
- Open note: `Home.md` (create as your vault homepage)
