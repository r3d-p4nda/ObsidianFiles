# Canvas Workflow (Advanced Canvas + Simple CanvaSearch)

## Suggested conventions
- Node colors:
  - Blue: goals
  - Yellow: assumptions
  - Green: actions
  - Red: blockers
- Prefix task nodes with `TASK:` so they are easy to query.

## Search patterns for Simple CanvaSearch
- `TASK:`
- `owner:`
- `due:`
- `risk:`

## Operational rhythm
1. Weekly review: open key project canvas.
2. Convert `TASK:` nodes into TaskNotes.
3. Link each task note back to the canvas file.
