# Copilot Prompt Library

## Clarify project
"Given this project note, list missing assumptions, risks, and first 5 execution steps."

## Turn notes into tasks
"Convert the discussion notes into actionable tasks with owner, due date suggestion, and priority."

## Weekly synthesis
"Summarize this week across daily notes into wins, blockers, and top 3 priorities for next week."

## Knowledge expansion
"Suggest related concepts and 3 evergreen notes I should create from this literature note."
